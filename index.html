A few little questions.

Do I need an account or payment?

No. The current collection and editor are free to use without registering.

Where is my message stored?

The shared link contains the card. Anyone with it can read it. Optional local drafts stay in this browser until you delete them.

Will my old card link work?

Yes. Previously supported v1, v2 and v3 card links remain supported.

Can I upload a photo or use AI?

These features are not available in this release. Your existing local illustrations and editor work without a backend.
