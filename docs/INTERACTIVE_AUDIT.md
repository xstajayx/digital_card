# Interactive experience audit

Baseline e997958, subsequently observed merged into main at e6bd700 with identical source tree. This branch inherits the previous unmerged increments. Existing shop, 28 designs, six fonts, original illustrations/aliases, five-step editor, measured fitting, storage-optional drafts and copy/native/WhatsApp all remain useful. Before source changes, 12 data tests and all 24 baseline browser check groups passed; results are recorded in INTERACTIVE_DELIVERY.md.

Confirmed gap: opening type lives in a template's features and the controller animates the entire flat object, so an envelope cannot be chosen independently for every design. The v3 compact payload is a 13-element array without opening configuration. It must stay unchanged. New fields require a new version with strict validation and an explicit legacy decoding route.

Recipient already shares the same renderer and fitting, but does not identify the sender in its introduction. Sharing lacks email/SMS composition and QR. AI remains an honest availability page without service integration. Local media and paid services are absent and will not be introduced as placeholders.

Plan: additive v4 envelope around the unchanged compact v3 content, independent validated opening and effect controls, layered envelope/gift animation, recipient introduction, and useful no-backend email/SMS workflows. Preserve the original eight effects and all older URL formats. Remaining advanced openings, QR and remote capabilities must be explicitly reported if unfinished. No deployment, DNS, EV Revival or paid calls are part of this work.
